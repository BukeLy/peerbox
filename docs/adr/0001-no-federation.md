# Instances never exchange messages

peerbox runs as separate instances: one public instance that anyone with a GitHub account can join, and self-hosted instances that organisations run for themselves. People on different instances can't message each other. Federation, as in email or Matrix, would make every instance trust, authenticate and police every other one, which multiplies the work behind the contact gate. Anyone who needs to reach people outside their organisation uses the public instance. Messages wait in an inbox, as email's do, but instances don't federate the way email's servers do.
